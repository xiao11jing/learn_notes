# learn_notes

一个用于「学 Django + 记录学习过程」的个人仓库。

## 目录

| 路径 | 用途 |
|---|---|
| project.md | 学习计划、阶段路线、规则与决策点（先读这个） |
| notes/pitfalls.md | 弃坑日志：每次想放弃时记一行 |
| notes/glossary.md | 代码词典：遇到不懂的函数/参数记一行 |
| notes/weekly.md | 每周一句进度汇报 |
| app/ | Django 项目（后续创建） |

## 原则

- 记录寄生在工作流里：commit、issue、每行注释，不额外写长篇笔记。
- 每天一个小 commit，比每周一次大提交有效。
- 中断不丢人，48 小时内回来一次就行。
